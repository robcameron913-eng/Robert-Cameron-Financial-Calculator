Formula Explanations

Holding Period Return: (Ending Price - Beginning Price) / Beginning Price

Annualized Return: Converts the selected-period return into a yearly return.

Excess Return: SAIA annualized return minus SPY annualized return.

Volatility: Standard deviation of daily returns, annualized using √252 trading days.

Beta: Covariance of SAIA returns and market returns divided by variance of market returns.

Correlation: Measures how closely SAIA and SPY move together.

Alpha: Actual annualized return minus expected return under CAPM.

Sharpe Ratio: (Annualized return - risk-free rate) / annualized volatility.

Treynor Ratio: (Annualized return - risk-free rate) / beta.

Portfolio Return: Weighted average return of SAIA and SPY.
